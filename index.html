    WHY OPEN INNOVATION?

    AI that helps you disconnect.

    WildQuest uses an open-weight AI model through Transformers.js. Its goal is to generate useful outdoor activities while keeping user preferences in the browser. Open models give developers more freedom to inspect, adapt and replace the AI. No paid inference API is required. The model needs an initial download, so fully offline operation depends on browser caching and setup.
